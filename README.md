# ГРП — схема скважины

Полностью статическое приложение для GitHub Pages. Опубликуйте содержимое репозитория через Pages — установка зависимостей и сервер не нужны.

Локальный запуск:

```powershell
npm start
```

После запуска откройте `http://localhost:8080`.

Приложение читает только первый лист XLSX. Файл обрабатывается локально в браузере и никуда не отправляется. SheetJS 0.18.5 хранится локально в `vendor/xlsx.full.min.js`, поэтому подключение к интернету не требуется.

Готовые наборы находятся в `data/<скважина>/`: конструкция — в `common.json`, список испытаний — в `experiments/index.json`, исходный сигнал и кепстр — в `experiments/<номер>.json`. Повторная генерация из исходных XLSX: `node tools/export-data.js`.

При открытии через `file://` браузер может запрещать чтение JSON через `fetch`. На GitHub Pages готовые наборы работают штатно; локальная загрузка XLSX доступна в любом случае.

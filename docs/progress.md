# Прогресс

## Реализовано

- Два режима данных: встроенные JSON и загрузка XLSX.
- Парсинг конструкции, испытаний, исходного сигнала и кепстра.
- Линейная схема скважины с НКТ, муфтами, шаром и изолированным участком.
- Три графика: сохранённый кепстр, расчётный кепстр и исходный сигнал.
- Сворачивание графиков и корректная перерисовка скрытых SVG.
- Переключение испытаний селектом и клавишами `↑`/`↓`.
- Локальная SheetJS и статическая публикация на GitHub Pages.
- Интерактивная импульсная симуляция с синтетическим сигналом, кепстром и регуляторами шума, скорости, затухания и ширины импульса.
- Миниатюра всех объектов скважины в sticky-шапке.

## Ограничения

- Испытания без парного листа показывают сообщение об отсутствии данных.
- Исходные XLSX остаются в корне как источник генерации.
- Расчётный стандартный кепстр не обязан совпадать с сохранённым кепстром XLSX.

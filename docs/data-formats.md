# Форматы данных

## XLSX

Первая страница обычно называется `Конструкция`:

- под `Порт` и `Глубина` идёт непрерывный блок перфораций;
- конец НКТ ищется в строке заголовка в одной из трёх ячеек справа от `НКТ`;
- ниже конструкции находится таблица испытаний: A — номер, B — название;
- номер порта шара ищется сначала в начале названия, иначе в конце: `4_НТ`, `4 огрп`, `минигрп 4`, `ogrp_1`;
- номер принимается только при наличии соответствующего порта;
- лист исходного сигнала называется номером испытания: `1`, `2`, ...;
- лист кепстра называется `<номер>c`; встречаются латинская `c` и кириллическая `с`.

Листы сигнала и кепстра состоят из двух числовых столбцов `X/Y` без заголовка.

## JSON

```text
data/
  catalog.json
  <скважина>/
    common.json
    experiments/
      index.json
      <id>.json
```

- `common.json` — конец НКТ и перфорации.
- `experiments/index.json` — краткий список испытаний.
- `experiments/<id>.json` — метаданные, положение шара, исходный сигнал и кепстр.

Генерация:

```powershell
node tools/export-data.js
```

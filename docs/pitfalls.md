# Грабли и важные детали

## Парсинг

- `Number(null)` и `Number('')` дают `0`. Сначала отвергать `null`, `undefined` и пустую строку, иначе появляется ложная перфорация `(0, 0)`.
- Нельзя полагаться на фиксированную ячейку НКТ: исходные файлы различаются.
- Нельзя искать номер шара только в начале названия.
- Кириллическая `с` в имени листа визуально неотличима от латинской `c`; имена нормализуются.

## Графики

- Автомасштаб кепстра по абсолютным min/max неверен: сильные краевые выбросы сжимают полезный сигнал в сотни раз.
- Сохранённый в XLSX кепстр не совпадает буквально со стандартным вещественным кепстром. Вероятно, исходный процесс использовал собственную обработку фазы или нормировку; графики сравнительные, не идентичные.
- Разные фиксированные `viewBox` при `width:100%` создают разные боковые поля. Ширина должна соответствовать `clientWidth`.
- У скрытого через `display:none` SVG `clientWidth` равен 0. При фоновой отрисовке брать `parentElement.clientWidth`, иначе после раскрытия график сжимается.
- После изменения высоты `viewBox` проверять нижние подписи; ранее глубины попадали на Y=302 при границе 300.
- CSS не предоставляет надёжного селектора состояния «sticky уже прилип». Состояние шапки и момент прилипания скважины вычисляются по экранным координатам sentinel, шапки и SVG в обработчике прокрутки, ограниченном через `requestAnimationFrame`. Sticky-элемент нельзя оставлять внутри `.card` с `overflow:hidden`: такой предок становится ограничивающим scroll-контейнером.
- Нельзя добавлять sticky-копию в поток только при `is-stuck`: изменение высоты шапки вызывает неприятный скачок страницы при отлипании. Копия всегда существует как абсолютный слой под шапкой и переключается через `visibility`; её появление не влияет на layout.
- Момент появления sticky-копии нельзя привязывать к одному лишь закреплению шапки: тогда она дублирует ещё видимую полную схему. На прокрутке сравниваются экранные Y-координаты осей обеих схем с учётом `WELL_GEOMETRY`; обновление ограничено одним `requestAnimationFrame` на кадр.
- Для бесшовной подмены недостаточно совместить только оси. Нижние границы исходного SVG и sticky-копии тоже должны совпадать в момент прилипания: нижний отступ от объектов одинаков и равен 8 px. Геометрические константы обеих схем хранятся вместе в `WELL_GEOMETRY`.
- Глобальную направляющую курсора нельзя обновлять напрямую на каждом `pointermove`: частота событий выше частоты кадров. Координата применяется через один запланированный `requestAnimationFrame`; слой имеет `pointer-events:none`.
- Интерактивный шум нельзя генерировать новым `Math.random()` на каждом движении ползунка: пользователь не сможет отличить влияние амплитуды от нового случайного рисунка. Используется детерминированный PRNG с seed по скважине, испытанию и порту.

## Развёртывание

- JSON нельзя загружать через `fetch` при `file://`; нужен HTTP.
- SheetJS хранится локально, чтобы GitHub Pages не зависел от CDN.

# Грабли и важные детали

## Парсинг

- `Number(null)` и `Number('')` дают `0`. Сначала отвергать `null`, `undefined` и пустую строку, иначе появляется ложная перфорация `(0, 0)`.
- Нельзя полагаться на фиксированную ячейку НКТ: исходные файлы различаются.
- Нельзя искать номер шара только в начале названия.
- Кириллическая `с` в имени листа визуально неотличима от латинской `c`; имена нормализуются.

## Графики

- Автомасштаб кепстра по абсолютным min/max неверен: сильные краевые выбросы сжимают полезный сигнал в сотни раз.
- Сохранённый в XLSX кепстр не совпадает буквально со стандартным вещественным кепстром. Вероятно, исходный процесс использовал собственную обработку фазы или нормировку; графики сравнительные, не идентичные.
- Разные фиксированные `viewBox` при `width:100%` создают разные боковые поля. Ширина должна соответствовать `clientWidth`.
- У скрытого через `display:none` SVG `clientWidth` равен 0. При фоновой отрисовке брать `parentElement.clientWidth`, иначе после раскрытия график сжимается.
- После изменения высоты `viewBox` проверять нижние подписи; ранее глубины попадали на Y=302 при границе 300.

## Развёртывание

- JSON нельзя загружать через `fetch` при `file://`; нужен HTTP.
- SheetJS хранится локально, чтобы GitHub Pages не зависел от CDN.

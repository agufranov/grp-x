# Архитектура

## Назначение

Статический браузерный просмотрщик и интерактивный симулятор данных ГРП. Показывает конструкцию горизонтальной скважины, измеренные графики и синтетический отклик. Предназначен для GitHub Pages; production-бэкенд и сборка не нужны.

Пользователь может:

1. Выбрать заранее подготовленный JSON-набор.
2. Выбрать в селекте скважины пункт `＋ Загрузить XLSX…` и обработать файл локально в браузере.
3. Переключать испытания селектом или глобальными клавишами `↑`/`↓`.

## Локальный запуск

```powershell
npm start
```

Открыть `http://localhost:8080`. Прямой запуск через `file://` не подходит для JSON-наборов: браузер блокирует `fetch` из-за CORS. На GitHub Pages это ограничение отсутствует.

## Основные файлы

- `index.html` — компактная рабочая разметка.
- `styles.css`, `overrides.css`, `charts-extra.css` — оформление.
- `interpolation.js` — линейная и сохраняющая форму PCHIP-интерполяция на неравномерной временной сетке; модуль доступен браузеру и Node.js-тестам.
- `app.js` — парсинг, модель, подготовка сигнала, FFT и SVG-отрисовка.
- `tools/test-interpolation.js` — регрессионные проверки интерполяции без внешних зависимостей.
- `vendor/xlsx.full.min.js` — локальная SheetJS 0.18.5.
- `tools/export-data.js` — генератор JSON из XLSX.
- `data/` — встроенные наборы.
- `7714_1.xlsx`, `7716.xlsx` — исходники для повторной генерации.

Тяжёлый JSON конкретного испытания загружается лениво после выбора испытания.
